# Dindimpudim 🍮

Jogo de pet virtual **offline-first** (PWA / Android) desenvolvido por **Ela Fullstack** (`elafullstack`).

## Sobre o Projeto
- **Cuidado e evolução:** Cuide do seu Dindimpudim do estágio Bebê ao Idoso, com personalização livre de nome, aparência e tratamento.
- **Conexão local e futuro online:** Funciona offline no dispositivo, com interação local via Wi-Fi / Bluetooth (estilo *Dual*) e arquitetura preparada para futura sincronização de conta e ranking global.
- **Transparência e Privacidade:** Consulte os termos completos em [Política de Privacidade](./privacy.md).
